本地运行 · 无需构建

HTML 可视化编辑器

把 HTML 放进来，直接在页面上选中元素、调整样式、编辑文字，最后导出一份干净文件。

运行方式纯前端
编辑模式点选元素
导出结果清除编辑器代码

拖拽 HTML 文件到这里

支持 .html / .htm，也可以点击选择文件
上传 HTML 后会自动进入编辑模式；粘贴代码后可编辑当前代码。
直接点选进入编辑模式后选中页面元素，右侧面板实时改样式。
可撤销支持撤销、重做、文字编辑、页面切换等常用操作。
干净导出复制或下载时会移除编辑器自身注入的代码。

也可以直接在 HTML 文件底部加入 <script src="editor.js"></script>。
